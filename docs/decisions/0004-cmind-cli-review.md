# ADR-0004 — явная CLI-область global review CoderMind

Статус: ACCEPTED инженерным агентом в рамках поручения завершить прототип;
предметные требования и критерии Checker не меняются.

## Основание

На базовом pin `3303a222eaec42c6a178bddd46ad63d9026ab8fa` native global review
выполнил 10 итераций: функциональные проверки и post-pytest PASS, заглушек нет,
но общий verdict FAIL. В `code_gen/global_review.py` отсутствие страниц/скриншотов
безусловно переопределяет DONE даже для CLI, хотя prompt требует visuals только
для web/GUI. Полный неуспешный результат сохранён в checker-v1. Подделывать
счётчики screenshots или добавлять продукту ненужный GUI недопустимо.

## Решение и альтернативы

Использовать изолированную копию того же pinned пакета с версионированным patch:
`--review-interface cli` делает визуальные проверки неприменимыми только при
явно выбранной CLI-области. По умолчанию `visual`: прежнее требование страниц/
скриншотов сохраняется. pytest, stub detection, функциональные и unresolved
checklist checks не меняются. CLI-применимость обоснована принятым IF-1.

Альтернативы: оставить product acceptance незавершённой до upstream fix либо
обновить весь CoderMind без оценки изменений. Малый воспроизводимый patch
ограничивает поверхность изменения двумя файлами. Он является локальной
вариацией инструмента; результат не объявляется PASS неизменённого upstream.

## Границы и проверка

Исходная установка CoderMind не меняется. `prepare_cmind_cli_review.py` сверяет
base revision, исходные SHA256 и patch SHA256, создаёт копию в cache и проверяет
хеши результата. CLI запускается штатным `cmind script` с PYTHONPATH этой копии.
Важные guard cases проверяются без модели: CLI без screenshots допускается,
visual/default без screenshots отклоняется, падение pytest, заглушки и unresolved
functional items остаются блокирующими. После этого выполняется настоящий
model-driven native global review в CLI-области, не имитация его результата.

Изменение касается dev-интеграции, не runtime/домена. В Git сохраняются patch,
его идентичность, результаты regression и обоих native запусков. После upstream
исправления patch следует удалить при отдельном обновлении pin. Полная
воспроизводимость clean toolchain/model runs пока не доказана.
