# ADR-0001: независимая лаборатория

Статус: **ACCEPTED**, 2026-10-16.

## Контекст

Цель — изучить методику работы агентов с инженерным графом Harness и реализационным RPG от постановки до кода, а не реализовать весь Product, SSSR или NAPMS. Владелец уже создал новый репозиторий agentic-checker-lab, работает в Ubuntu, разрешил начальный bootstrap в main и требует дальнейшие PR/squash.

## Альтернативы

- Отдельная research branch в Product: риски наследования старой реализации и смешение результатов с legacy.
- Использовать NAPMS main/branch: смешение с принятыми требованиями/архитектурой более крупного продукта.
- Отдельная лаборатория с pinned links к источникам: независимые архитектурные эксперименты, воспроизводимость и возможность повторить задачу в контрольных вариантах.

## Решение

Использовать **отдельный репозиторий**. Harness и RPG выступают **dev-time tooling** и не связывают runtime Checker. Product/SSSR/NAPMS неизменны, их версии фиксируются как evidence. Единственное исключение из последующих PR/squash: bootstrap пустого репозитория.

## Последствия

Нужны version pin, отдельные research/accepted truth, независимые тесты, связь графов, контроль стоимости и отдельное принятие целевой минимальной спецификации Checker. Принятие ADR не означает выбора полного DDD, API, архитектуры, CLI агента или бизнес-verdict.
