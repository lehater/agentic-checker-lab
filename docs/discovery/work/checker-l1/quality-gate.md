## Bounded risk challenge (3 focused counterexamples)

1. **Missing source port + extra condition:** src/dst IP, TCP, destination 443, absent source port; stored ACL has matching TCP five fields and supplemental time-range. Expected under recorded meanings: wildcard source-port search, matched rule reported together with uninterpreted condition; never call it an end-to-end permit verdict. Candidate's mandatory-integer schema would reject this input.
2. **Zero ACL + zero FW:** device FW-A relevant with zero ACL, FW-B irrelevant; report must include FW-A even without children, exclude FW-B. If no relevant FW at all, report an empty FW set. Provider based solely on pairs cannot encode the FW-A case.
3. **Identical line multiplicity + missing evidence:** ACL A has two identical literal rows at different saved positions and two relevant attachments; ACL B is relevant but has no successful snapshot. For A, retain both saved row occurrences in one ACL group. For B, do not assert `NO_MATCH`; exact global/per-ACL error contract remains an **engineering proposal**.

These are **targeted consistency/weak-coverage challenges** for the current L1 candidate, mostly based on earlier reviews. They are **not claimed as newly discovered owner questions**. No separate full Deep review, model calls or owner interview is justified at this point.
