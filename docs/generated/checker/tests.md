> Generated from Harness canonical knowledge. Do not edit this file directly.

## Purpose

Executable public contracts from pre-code expectations, independent of implementation.

## Test contracts

### TD-BEHAVIOR

Verification:

- VC-INPUT
- VC-MATCH
- VC-CONTEXT
- VC-EMPTY

**Precondition:** docs/checker/scenarios.yaml fixed cases; input serialized per IF-1.

**Operation:** Run every scenario against the public CLI as an isolated process, with JSON output.

**Oracle:** Compare fixed expected IDs, actions, groups/status, complete original fields, placements, no verdict; errors exit 2 with empty stdout.

### TD-BOUNDARIES

Verification:

- VC-ARCH
- VC-IF

**Precondition:** Accepted IF-1 and ARCH-1/POL-1; local synthetic fixture.

**Operation:** Run text and JSON CLI, malformed JSON and shape/unsupported/absent data cases; inspect inner module imports.

**Oracle:** Text shows groups/rules/placements; JSON shape matches contract; bad data never becomes success; inner modules do not import outer adapters or network/filesystem modules.
