## Виды истины

- ACCEPTED: человеком утверждённый смысл, ограничение или инженерное решение.
- VERIFIED: результат реально выполненной проверки с входом, средой, версиями и evidence.
- PROPOSED: кандидат, ещё не допущенный в реализацию.
- UNKNOWN / BLOCKED: существенного подтверждения нет; нельзя выдавать предположение за факт.
- SUPERSEDED: историческое решение, которое более не определяет текущее поведение.

Одно утверждение — один канонический владелец. Другие документы ссылаются на него, не создают самостоятельные копии. Research хранит доказательства и гипотезы. Generated diagrams, RPG snapshots и CI output — проверочные/производные артефакты, не источник предметной истины.

## Навигация агента

Корневой AGENTS.md — краткая карта. Сначала индекс, текущее состояние и постановка задачи; затем — только непосредственно затронутые документы и зависимости. Подробные правила содержатся в governance.md, а не в постоянно загружаемом промпте.
