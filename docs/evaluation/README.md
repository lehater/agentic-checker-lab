# Evaluation: независимая проверка и сравнение

Статус: независимые проверки первого Checker исполняются; результаты находятся в [прогоне checker-v1](../../experiments/runs/checker-v1/README.md). Контролируемое сравнение A/B/C/D ещё не проведено.

Основной риск — круговая проверка: агент сам выводит требования, пишет код и пишет тесты к собственному пониманию. Независимые acceptance cases должны происходить из утверждённого смысла, с согласованным входом/выходом, прежде чем тот же агент пишет реализацию. Скрытые кейсы предусмотрены сравнительным протоколом. В текущем пилоте сценарии были зафиксированы до кода, но доступны генератору; blinded/held-out оценка не заявлена.

Результат отдельного кейса: NOT_RUN, PASS, FAIL, BLOCKED или INCONCLUSIVE. Наличие тестового файла не является результатом тестирования.
