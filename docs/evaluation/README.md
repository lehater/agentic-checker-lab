# Evaluation: независимая проверка и сравнение

Статус: **активный экспериментальный протокол, сравнение ещё не выполнено**. Историческая реализация Checker с тестами и частичным воспроизводимым прогоном существует в [PR #27](https://github.com/lehater/agentic-checker-lab/pull/27), но в `main` не слита и не является новым контролируемым сравнением.

Основной риск — круговая проверка: агент выводит требования, пишет код и сам себе тесты. Независимые критические сценарии должны происходить из принятой спецификации до генерации; после её начала ожидаемые результаты нельзя переписывать под код.

Новый эксперимент: direct Codex против CoderMind/RPG + Codex при одинаковых спецификациях. Отдельно измеряется архитектурная корректность и стоимость/время. Обычные `PASS/FAIL/BLOCKED/INCONCLUSIVE/NOT_RUN` относятся к конкретному запуску с доказательствами, а не к наличию файла или PR.
