# Промежуточный срез Checker — 2026-10-16

Исторический срез; последующее завершение и текущие результаты — [в отчёте прогона](README.md).

Срез опубликован для оценки владельцем; реализация не принята как CURRENT через Harness.

## Что можно проверить

Из корня репозитория, Python 3.10+; сторонние runtime-зависимости не нужны:

```bash
python3 -m checker --input examples/checker-input.json
python3 -m checker --input examples/checker-input.json --format json
python3 -m unittest discover -s tests -p 'test_checker_*.py' -v
make check
```

CLI показывает все совпавшие сохранённые правила по device/ACL с исходными
действиями и порядком. Поддерживаются IPv4, TCP/UDP, CIDR и включительные диапазоны
портов. Итоговый вердикт о доступности не вычисляется. Источники синтетические.
Ошибочные или неполные входные данные завершают запрос с кодом 2.

## Происхождение и свидетельства

Код `checker/` и `src/` скопирован без изменений из неизменяемого коммита
CoderMind `3f0cbdabb099632f8ad538fecf3ce21c504b1d82` изолированного workspace.
Все 19 файлов сверены по SHA256 с `candidate-independent.json`.
На этом кандидате прошли 10 независимых тестовых методов, включая 15 заранее
зафиксированных сценариев; после переноса те же 10 методов повторно прошли
в корне репозитория. Ожидания сценариев не изменялись при переносе. Структурный тест уточнён:
убран общий запрет `sys` (совместимость типов со стандартной библиотекой не
нарушает границы), а порядок и количество внутренних lookup-вызовов заменены
проверкой аргументов и наблюдаемого результата. Договор не предписывает
кэширование и расписание lookup; проверки порядка групп, дедупликации,
неизменности входов и распространения ошибок сохранены.

Принятые инженерные документы: `docs/checker/`; публикация знаний:
`.harness/project-publication.yaml`. RPG, его семантические проверки и история
исправления расхождений сохранены в этом каталоге эксперимента.

## Что ещё не завершено

- Полный native-цикл CoderMind, final-test и global-review.
- Мутационные проверки: `mutations.py` подготовлен, запуск ещё не заявлен.
- Формальная сверка реализации с Test Design и итоговая Harness admission.
- Финальная привязка traceability к исходникам и полное закрытие CHECKER-PROTOTYPE.

Фоновая генерация продолжает работу в изолированном workspace. Этот Git-срез
содержит только указанный неизменяемый кандидат; последующие изменения native
workspace в него автоматически не попадают. Production readiness и завершение
эксперимента не заявлены.
